/quality, the proof strip, and dark mode

Same direction B as the approved home page: petal paper, plum ink, rose brush marks, Schibsted Grotesk. The idea for /quality: it reads like a signed test report, not a dashboard. Every requirement row carries the same brush tick that marks verifiable certifications, so the tick means one thing everywhere: "this was checked". Numbers are sample data. Click any frame you want to comment on, then tell me in the terminal.
